# VeriFactu.dev - API de Facturación Electrónica Obligatoria

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Stripe-like API para Verifactu (facturación electrónica obligatoria en España).

## 🌐 Sitio

- **Web**: [https://verifactu.dev](https://verifactu.dev)
- **Precios**: [https://verifactu.dev/precios](https://verifactu.dev/precios)
- **Docs**: [https://verifactu.dev/documentacion](https://verifactu.dev/documentacion)
- **Blog**: [https://verifactu.dev/blog](https://verifactu.dev/blog)
- **Directorio**: [https://verifactu.dev/directorio](https://verifactu.dev/directorio)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📁 Estructura

```
src/
├── app/
│   ├── page.tsx          # Landing principal
│   ├── precios/         # Página de precios
│   ├── documentacion/    # Documentación API
│   ├── blog/            # Artículos SEO
│   │   ├── que-es-verifactu/
│   │   ├── fechas-obligacion/
│   │   └── ...
│   ├── directorio/      # Directorio programas
│   └── contacto/        # Página de contacto
└── components/
    ├── Header.tsx
    └── Footer.tsx
```

## 🛠 Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
- **Hosting**: Neon (PostgreSQL)
